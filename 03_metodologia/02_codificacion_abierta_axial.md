# Codificación abierta y axial (antes del affinity mapping)

El affinity map es más sólido cuando se construye sobre datos ya codificados. Por eso el proceso tiene tres momentos:

```
Transcripciones → Codificación abierta → Codificación axial → Affinity mapping (clusters)
```

## 1. Codificación abierta

Objetivo: fragmentar los datos y etiquetarlos sin categorías previas.

- Lee cada transcripción y separa **fragmentos** con significado propio (una idea, un hecho, una emoción, un comportamiento).
- A cada fragmento asígnale un **código**: una etiqueta corta (2 a 5 palabras) que describa qué está pasando. Preferir verbos o acciones ("posterga pagos", "desconfía de apps") sobre temas genéricos ("dinero", "tecnología").
- Usa **códigos in vivo** (palabras textuales del entrevistado) cuando expresen algo con fuerza.
- Clasifica cada fragmento por **tipo**: dolor, motivación, frustración, comportamiento, necesidad, creencia, contexto, workaround (solución improvisada).
- Registra la **intensidad emocional** percibida (alta / media / baja).
- Cada fragmento conserva su referencia: `E01-F03` (entrevista 01, fragmento 03).

## 2. Codificación axial

Objetivo: relacionar los códigos entre sí y agruparlos en categorías.

- Agrupa códigos similares en **categorías** (y subcategorías si hace falta).
- Para cada categoría identifica, cuando la evidencia lo permita:
  - **Condiciones causales:** qué origina el fenómeno.
  - **Contexto:** en qué situaciones aparece.
  - **Estrategias / acciones:** qué hacen los usuarios frente a eso.
  - **Consecuencias:** qué resultado tiene para ellos.
- Señala las relaciones entre categorías (causa → efecto, una refuerza a otra, una contradice a otra).
- Distingue síntoma (lo que se ve) de causa (lo que lo origina).

## 3. Affinity mapping

Objetivo: sintetizar las categorías en clusters accionables para el startup.

- Construye clusters a partir de las categorías axiales, buscando significado profundo, no palabras similares.
- Un código o categoría puede pertenecer a más de un cluster si es necesario.
- Prioriza los clusters con los criterios de `03_criterios_priorizacion.md`.
