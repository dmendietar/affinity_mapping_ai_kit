# Entrevistas y validaciones

Copia aquí las transcripciones (formato `.txt`, `.md` o `.docx`). Un archivo por entrevista.

## Convención de nombres

`E01_segmento_perfil.txt`, `E02_segmento_perfil.txt`, ...

Ejemplo: `E01_madres_trabajadoras_Lima.txt`, `E02_madres_trabajadoras_Arequipa.txt`.

El código `E01`, `E02`... se usa en todo el análisis para citar de dónde viene cada fragmento, así que no lo cambies una vez empezado.

## Encabezado sugerido al inicio de cada transcripción

```
Código: E01
Fecha:
Entrevistador/a:
Segmento:
Perfil del entrevistado (sin datos personales sensibles):
Tipo: entrevista de problema / validación de solución / otro
```

## Recomendaciones

- Anonimiza nombres y datos personales antes de usar la IA.
- Mantén las respuestas textuales del entrevistado; no las resumas.
- Si tienes notas de observación, agrégalas al final marcadas como `[OBSERVACIÓN]`.
